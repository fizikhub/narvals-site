Core Web Vitals skoru neden sürekli değişir?

Laboratuvar (Lighthouse) testleri simülasyondur; Google'ın dikkate aldığı asıl metrik ise son 28 gün içindeki gerçek kullanıcıların (CrUX) saha verileridir.

Hangi optimizasyon en hızlı etkiyi sağlar?

Hero görselini WebP formatına geçirip fetchpriority="high" eklemek ve kullanılmayan 3. taraf analiz scriptlerini kaldırmak LCP ve INP skorunu anında %40–50 iyileştirir.
