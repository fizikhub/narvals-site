Sık Sorulan Sorular

Görsel boyutları hakkında.

Web sitelerinde görseller neden yavaş yüklenir?

Çoğu web sitesi 4000x3000 piksel boyutundaki devasa fotoğrafları doğrudan yükler. Görselleri gösterileceği maksimum boyuta (örn. 1200x800) ölçeklemek sayfa hızını 5 kat artırır.

WebP mi JPEG mi tercih edilmeli?

WebP formatı, aynı görsel kalitesini JPEG'e göre %30–35 daha küçük dosya boyutunda sunar. Web sitelerinde kesinlikle WebP veya AVIF tercih edilmelidir.
